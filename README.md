# Что надеть — погода в реальном времени

Веб-приложение на React, которое показывает текущую погоду в выбранном городе, подсказывает, как одеться, и желает хорошего дня с учётом погоды.

## Возможности

- Поиск любого города мира с подсказками по мере ввода и выбором с клавиатуры
- Определение города по геолокации браузера
- Запоминание последнего выбранного города: при следующем визите погода открывается сразу
- Текущая погода: температура, ощущается как, ветер и порывы, влажность, вероятность осадков, максимум и минимум за день
- Автоматическое обновление данных каждые 10 минут, при возвращении на вкладку и по кнопке «Обновить»
- Цвет страницы меняется вместе с погодой: ясно, облачно, дождь, снег, гроза, туман, ночь
- Советы, что надеть: верх, низ, обувь и аксессуары по температуре «ощущается как», с поправками на дождь, снег, гололёд, ветер, солнце и перепад температур за день
- Пожелание на день, которое зависит от погоды и местного времени в городе: утро, день, вечер, ночь
- Адаптивная вёрстка для телефонов
- Понятные сообщения, если город не найден, погода не загрузилась или доступ к геолокации запрещён

## Технологии

- [React 18](https://react.dev) и [Vite 5](https://vitejs.dev)
- [Open-Meteo](https://open-meteo.com) — прогноз погоды и поиск городов
- [BigDataCloud Reverse Geocoding](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api) — название города по координатам при геолокации
- Шрифты Unbounded и Onest из Google Fonts (поддерживают кириллицу)

Оба API бесплатные и **не требуют ключей**, поэтому проект запускается сразу после клонирования.

## Запуск

Нужен Node.js 18 или новее.

```bash
git clone <адрес-вашего-репозитория>
cd weather-wear
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build     # результат в папке dist/
npm run preview   # локальный просмотр собранной версии
```

## План разработки

Проект разрабатывается в три этапа.

### Этап 1. Погода в реальном времени — готово

- [x] Проект на Vite + React, README
- [x] Поиск города через Open-Meteo Geocoding API: подсказки при вводе, выбор стрелками и Enter, сообщения «город не найден» и «поиск недоступен»
- [x] Загрузка текущей погоды и сводки на сегодня: температура, ощущается как, ветер и порывы, влажность, вероятность осадков, максимум и минимум
- [x] Автообновление каждые 10 минут и при возвращении на вкладку, кнопка «Обновить», время последнего обновления
- [x] Цветовая тема страницы по текущей погоде, отдельная ночная тема
- [x] Расшифровка кодов погоды WMO на русском языке

### Этап 2. Советы по одежде — готово

- [x] Подбор одежды по температуре «ощущается как»: восемь диапазонов от сильного мороза до жары
- [x] Поправки на погоду: дождь — непромокаемая куртка, обувь и зонт; снег и ледяной дождь — нескользящая обувь; сильный ветер — капюшон и шапка; высокий УФ-индекс — очки и крем с SPF
- [x] Блок «Что надеть» со списком по слоям: верх, низ, обувь, аксессуары
- [x] Учёт перепада температур за день: совет взять дополнительный слой
- [x] Пояснения, почему дан совет: вероятность осадков, скорость ветра, УФ-индекс

### Этап 3. Пожелания на день и доработки — готово

- [x] Пожелание на день по погоде: ясно, облачно, дождь, снег, гроза, туман, отдельно жара и мороз
- [x] Приветствие и пожелание по местному времени города: утро, день, вечер, ночь; вечером и ночью — пожелания отдохнуть с погодной припиской
- [x] Пожелание не меняется при каждом обновлении погоды в течение дня
- [x] Запоминание последнего выбранного города в браузере
- [x] Определение города по геолокации с понятными сообщениями, если доступ запрещён
- [x] Адаптивная вёрстка: на узких экранах поиск на всю ширину, показатели погоды в две колонки, увеличенные области нажатия на сенсорных экранах

Все три этапа завершены.
