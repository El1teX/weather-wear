# Что надеть — погода в реальном времени

Приложение на React для Telegram (Mini App) и браузера: показывает текущую погоду в выбранном городе, подсказывает, как одеться, и желает хорошего дня с учётом погоды.

Открыть в браузере: https://el1tex.github.io/weather-wear/

## Возможности

- Мультяшная живая сцена неба под текущую погоду: улыбающееся солнце и облака, которые моргают, капли дождя, кружащиеся снежинки, молнии, туман, сонная луна, звёзды и птицы
- Текущая погода: температура, ощущается как, максимум и минимум за день, ветер, вероятность осадков, влажность, УФ-индекс
- Дуга солнца: где солнце сейчас между восходом и закатом
- Что надеть: вещи с иконками по слоям (верх, низ, обувь, аксессуары) и пояснения, почему дан такой совет
- Пожелание на день по погоде и местному времени в городе
- Выбор города: поиск, «Моё местоположение» и недавние города
- Автообновление каждые 10 минут и кнопка обновления
- Работа внутри Telegram: цвета темы Telegram, системная кнопка «Назад», вибрация при нажатиях, облачное хранилище Telegram и геолокация через Telegram
- Адаптивная вёрстка для телефонов, поддержка тёмной темы и режима «уменьшить движение»

## Технологии

- [React 18](https://react.dev) и [Vite 5](https://vitejs.dev)
- [Open-Meteo](https://open-meteo.com) — прогноз погоды и поиск городов
- [BigDataCloud Reverse Geocoding](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api) — название города по координатам при геолокации
- [Telegram Mini Apps SDK](https://core.telegram.org/bots/webapps) — работа внутри Telegram
- Шрифт Nunito из Google Fonts: мягкий, округлый, с кириллицей

Оба API бесплатные и **не требуют ключей**, поэтому проект запускается сразу после клонирования.

## Запуск на компьютере

Нужен Node.js 18 или новее.

```bash
git clone https://github.com/El1teX/weather-wear.git
cd weather-wear
npm install
npm run dev
```

Откройте адрес из строки `Local` в терминале (обычно `http://localhost:5173`) и не закрывайте терминал, пока пользуетесь приложением. Вне Telegram приложение работает как обычный сайт.

Сборка для продакшена:

```bash
npm run build     # результат в папке dist/
npm run preview   # локальный просмотр собранной версии
```

## Публикация на GitHub Pages

Telegram открывает мини-приложения только по адресу с HTTPS, поэтому приложение публикуется на GitHub Pages.

1. В репозитории откройте **Settings → Pages**.
2. В поле **Source** выберите **GitHub Actions**.
3. Дальше всё происходит само: при каждом изменении в ветке `main` файл `.github/workflows/deploy.yml` собирает проект и публикует его. Ход публикации виден на вкладке **Actions**.

Адрес приложения: `https://el1tex.github.io/weather-wear/`.

## Подключение к Telegram

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и создайте бота командой `/newbot`: придумайте имя и адрес бота, который заканчивается на `bot`.
2. Создайте мини-приложение командой `/newapp`, выберите бота и ответьте на вопросы BotFather: название, описание, картинка 640×360. Когда попросят адрес, отправьте `https://el1tex.github.io/weather-wear/`. В конце придумайте короткое имя, например `weather`.
3. Приложение откроется по ссылке вида `https://t.me/<имя_бота>/weather`. Её можно отправить друзьям или закрепить в канале.
4. Чтобы приложение открывалось кнопкой рядом с полем ввода в чате с ботом: `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → отправьте тот же адрес и подпись кнопки, например «Погода».

Что делает приложение внутри Telegram:
- берёт цвета из темы Telegram и красит шапку в цвет неба;
- показывает системную кнопку «Назад» на экране выбора города;
- слегка вибрирует при нажатиях;
- хранит город и недавние города в облачном хранилище Telegram, поэтому они сохраняются на всех устройствах пользователя;
- запрашивает местоположение через Telegram. Если доступ запрещён, предлагает открыть настройки.

## План разработки

Проект разрабатывается в три этапа.

### Этап 1. Погода в реальном времени — готово

- [x] Проект на Vite + React, README
- [x] Поиск города через Open-Meteo Geocoding API: подсказки при вводе, выбор стрелками и Enter, сообщения «город не найден» и «поиск недоступен»
- [x] Загрузка текущей погоды и сводки на сегодня: температура, ощущается как, ветер и порывы, влажность, вероятность осадков, максимум и минимум
- [x] Автообновление каждые 10 минут и при возвращении на вкладку, кнопка «Обновить», время последнего обновления
- [x] Цветовая тема страницы по текущей погоде, отдельная ночная тема
- [x] Расшифровка кодов погоды WMO на русском языке

### Этап 2. Советы по одежде — готово

- [x] Подбор одежды по температуре «ощущается как»: восемь диапазонов от сильного мороза до жары
- [x] Поправки на погоду: дождь — непромокаемая куртка, обувь и зонт; снег и ледяной дождь — нескользящая обувь; сильный ветер — капюшон и шапка; высокий УФ-индекс — очки и крем с SPF
- [x] Блок «Что надеть» со списком по слоям: верх, низ, обувь, аксессуары
- [x] Учёт перепада температур за день: совет взять дополнительный слой
- [x] Пояснения, почему дан совет: вероятность осадков, скорость ветра, УФ-индекс

### Этап 3. Пожелания на день и доработки — готово

- [x] Пожелание на день по погоде: ясно, облачно, дождь, снег, гроза, туман, отдельно жара и мороз
- [x] Приветствие и пожелание по местному времени города: утро, день, вечер, ночь; вечером и ночью — пожелания отдохнуть с погодной припиской
- [x] Пожелание не меняется при каждом обновлении погоды в течение дня
- [x] Запоминание последнего выбранного города в браузере
- [x] Определение города по геолокации с понятными сообщениями, если доступ запрещён
- [x] Адаптивная вёрстка: на узких экранах поиск на всю ширину, показатели погоды в две колонки, увеличенные области нажатия на сенсорных экранах

Все три этапа завершены.

### Этап 4. Telegram Mini App и новый дизайн — готово

- [x] Подключение Telegram Mini Apps SDK: тема Telegram, цвет шапки, кнопка «Назад», вибрация
- [x] Хранение города в облачном хранилище Telegram, геолокация через Telegram
- [x] Автопубликация на GitHub Pages и инструкция по подключению к боту
- [x] Новый игривый дизайн: яркое небо с мультяшными анимированными объектами, мягкий шрифт Nunito, шторка с контентом, вещи с иконками, цветные плитки с подробностями и дуга солнца
