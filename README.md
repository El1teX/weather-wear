# Что надеть — погода в реальном времени

Веб-приложение на React, которое показывает текущую погоду в выбранном городе, подсказывает, как одеться, и желает хорошего дня с учётом погоды.

## Возможности

- Поиск любого города мира с подсказками по мере ввода и выбором с клавиатуры
- Текущая погода: температура, ощущается как, ветер и порывы, влажность, вероятность осадков, максимум и минимум за день
- Автоматическое обновление данных каждые 10 минут, при возвращении на вкладку и по кнопке «Обновить»
- Цвет страницы меняется вместе с погодой: ясно, облачно, дождь, снег, гроза, туман, ночь
- Понятные сообщения, если город не найден или погода не загрузилась

Советы по одежде и пожелания на день появятся в следующих этапах, см. план ниже.

## Технологии

- [React 18](https://react.dev) и [Vite 5](https://vitejs.dev)
- [Open-Meteo](https://open-meteo.com) — прогноз погоды и поиск городов. API бесплатный и **не требует ключа**, поэтому проект запускается сразу после клонирования.
- Шрифты Unbounded и Onest из Google Fonts (поддерживают кириллицу)

## Запуск

Нужен Node.js 18 или новее.

```bash
git clone <адрес-вашего-репозитория>
cd weather-wear
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build     # результат в папке dist/
npm run preview   # локальный просмотр собранной версии
```

## План разработки

Проект разрабатывается в три этапа.

### Этап 1. Погода в реальном времени — готово

- [x] Проект на Vite + React, README
- [x] Поиск города через Open-Meteo Geocoding API: подсказки при вводе, выбор стрелками и Enter, сообщения «город не найден» и «поиск недоступен»
- [x] Загрузка текущей погоды и сводки на сегодня: температура, ощущается как, ветер и порывы, влажность, вероятность осадков, максимум и минимум
- [x] Автообновление каждые 10 минут и при возвращении на вкладку, кнопка «Обновить», время последнего обновления
- [x] Цветовая тема страницы по текущей погоде, отдельная ночная тема
- [x] Расшифровка кодов погоды WMO на русском языке

Для следующих этапов уже заложено: API загружает УФ-индекс, время восхода и заката, а в `weatherCodes.js` есть проверки «дождь» и «снег».

### Этап 2. Советы по одежде — в планах

- [ ] Подбор одежды по температуре «ощущается как»: от сильного мороза до жары
- [ ] Поправки на погоду: дождь — непромокаемая куртка и зонт, снег — зимняя обувь, сильный ветер — ветровка и шапка, высокий УФ-индекс — очки и солнцезащитный крем
- [ ] Блок «Что надеть» со списком по слоям: верх, низ, обувь, аксессуары
- [ ] Учёт перепада температур за день: совет взять дополнительный слой

### Этап 3. Пожелания на день и доработки — в планах

- [ ] Пожелание на день, которое зависит от погоды и времени суток: утро, день, вечер, ночь
- [ ] Запоминание последнего выбранного города между визитами
- [ ] Определение города по геолокации браузера
- [ ] Проверка адаптивной вёрстки на телефонах и доступности с клавиатуры
