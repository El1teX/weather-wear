# Что надеть — погода в реальном времени

Веб-приложение на React, которое показывает текущую погоду в выбранном городе, подсказывает, как одеться, и желает хорошего дня с учётом погоды.

## Возможности

- Поиск любого города мира с подсказками по мере ввода
- Текущая погода: температура, ощущается как, влажность, ветер, осадки, минимум и максимум за день
- Автоматическое обновление данных каждые 10 минут и при возвращении на вкладку
- Цвет страницы меняется вместе с погодой: ясно, облачно, дождь, снег, гроза, туман, ночь
- Советы по одежде по слоям: верх, низ, обувь, аксессуары *(этап 2)*
- Пожелание на день, которое зависит от погоды и времени суток *(этап 3)*

## Технологии

- [React 18](https://react.dev) и [Vite 5](https://vitejs.dev)
- [Open-Meteo](https://open-meteo.com) — прогноз погоды и поиск городов. API бесплатный и **не требует ключа**, поэтому проект запускается сразу после клонирования.
- Шрифты Unbounded и Onest из Google Fonts (поддерживают кириллицу)

## Запуск

Нужен Node.js 18 или новее.

```bash
git clone <адрес-вашего-репозитория>
cd weather-wear
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build     # результат в папке dist/
npm run preview   # локальный просмотр собранной версии
```

## План разработки

Проект собирается в три этапа, каждый этап — отдельная волна коммитов.

### Этап 1 — погода в реальном времени ✅

- [x] Каркас проекта на Vite + React, README
- [x] Поиск города через Open-Meteo Geocoding API
- [x] Загрузка текущей погоды и прогноза на день
- [x] Автообновление каждые 10 минут, кнопка «Обновить»
- [x] Цветовая тема страницы по текущей погоде

### Этап 2 — советы по одежде

- [ ] Правила подбора одежды по температуре «ощущается как»
- [ ] Поправки на дождь, снег, ветер и УФ-индекс
- [ ] Блок «Что надеть» со списком по слоям

### Этап 3 — пожелания на день и доработки

- [ ] Пожелания на день по погоде и времени суток
- [ ] Запоминание последнего выбранного города
- [ ] Определение города по геолокации
- [ ] Финальная полировка интерфейса и адаптива
